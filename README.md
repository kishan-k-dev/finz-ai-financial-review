# Finz AI Financial Review — MVP

A fast interview-assignment implementation for the Finz Software Engineering Internship challenge.

## Stack
- Python + FastAPI
- SQLite
- Pandas
- HTML/CSS/JavaScript
- Optional OpenAI-compatible LLM

## Run locally
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
uvicorn app.main:app --reload
```
Open http://127.0.0.1:8000

## Workflow
1. Upload the Finz CSV/XLSX transaction dataset.
2. The backend normalizes common date/description/amount column names.
3. Transactions receive deterministic categories and low-confidence items are flagged for review.
4. Monthly P&L is calculated from SQLite transaction rows — never generated by the LLM.
5. Month-over-month variance is calculated from the P&L.
6. Users can correct a category.
7. The analyst endpoint answers common financial questions from verified application data. If an OpenAI API key is configured, the LLM receives verified context for explanation only.

## AI-native design
Use deterministic Python calculations for money. Use the LLM for interpretation and conversational investigation. The UI exposes evidence rather than allowing the model to invent financial totals.
